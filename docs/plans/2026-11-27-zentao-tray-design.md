# 禅道托盘助手设计

日期：2026-11-27

## 目标

使用 NSGo 和原生 Go 构建 Windows 托盘常驻程序，从禅道 `http://192.168.2.225/biz/my` 获取当前账号指派给本人的未完成任务和 Bug。程序提供主工作台、状态变化通知和禅道详情跳转，界面采用云白与钴蓝风格。

## 范围

- 禅道账号密码登录与会话维持。
- 读取“我的”页面中指派给当前账号的未完成任务和 Bug。
- 每 60 秒轮询，支持手动刷新；轮询间隔可在设置中调整。
- 首次启动建立基线，不补弹历史消息。
- 后续新增任务/Bug，或已有事项状态变化时发送系统通知。
- 点击通知打开主工作台并定位对应事项。
- 主工作台展示连接状态、汇总计数、分类列表、筛选和事项详情。
- 事项详情支持通过系统浏览器打开禅道页面。
- 关闭主窗口时隐藏到托盘；托盘菜单支持打开工作台、立即刷新、通知开关和退出。
- 暂不注册登录自启动。

## 非目标

- 不直接连接或修改禅道数据库。
- 不创建、修改、关闭或评论禅道任务/Bug。
- 不监控需求、测试用例或非当前账号负责的事项。
- 不实现多账号、消息同步历史或云端配置。
- 不将评论变化作为第一版通知触发条件。

## 方案选择

### 采用方案

NSGo 原生 UI + Go `net/http` Cookie 会话 + 禅道同源页面数据解析。

优点：

- 使用原生 Go，无浏览器或脚本运行时依赖。
- 不需要额外数据库权限。
- 可复用当前账号密码，无需先生成 API Token。
- NSGo 已支持 Windows 托盘、系统通知、通知点击、打开 URL、安全存储和主工作台所需组件。

约束：

- 页面结构变化可能影响解析，需要将解析逻辑隔离并测试。
- 禅道登录可能包含前端哈希或一次性字段，需要按真实登录流程实现。
- NSGo 当前要求 Go 1.27.3 或更新版本，本机 Go 1.24.22 需要先升级或使用自动工具链。

### 备选方案

1. 禅道开放 API Token：数据契约更稳定，但需要额外生成和管理 Token。
2. 只读数据库：字段完整，但需要数据库权限，耦合和权限风险最高。

## 架构

- `zentao` 包：账号登录、Cookie 会话、页面请求、任务/Bug 解析、事项标准化。
- `app` 包：应用状态、基线管理、轮询调度、变化检测、通知和跳转。
- NSGo 组件：主工作台、设置、事项详情、托盘菜单。
- 本地安全存储：Windows 凭据管理器，由 NSGo `cx.Secrets()` 提供。
- 本地状态文件：保存已见事项 ID、状态指纹、最后成功刷新时间和通知偏好；不保存明文密码。

## 数据模型

事项至少包含：

- 类型：任务或 Bug。
- 禅道 ID。
- 标题。
- 项目名称。
- 状态。
- 最后更新时间。
- 详情 URL。
- 稳定指纹：类型、ID 和状态。

变化判定：

- 首次成功拉取：建立基线，不发送通知。
- 新 ID：视为新增。
- 已存在 ID 的状态指纹变化：视为状态变化。
- 事项消失：仅从当前列表移除，不发送通知。
- 请求或解析失败：保留上一次成功数据和基线，不发送变化通知。

## 主工作台

- 顶部：应用名称、当前账号、连接状态、最后刷新时间、立即刷新按钮。
- 汇总卡片：未完成任务数、未解决 Bug 数、本轮新增数、本轮状态变化数。
- 筛选：全部、任务、Bug；可切换仅看本轮变化。
- 列表：类型标识、标题、项目、状态、更新时间。
- 详情：展示事项完整信息，提供“在禅道打开”和“关闭”。
- 异常状态：展示登录失效、网络失败、解析失败及重试入口。

视觉规范：

- 页面背景：`#F5F8FC`。
- 卡片背景：`#FFFFFF`。
- 主色/钴蓝：`#2563EB`。
- 主色深色：`#1D4ED8`。
- 主文字：`#172B4D`。
- 次文字：`#5E7184`。
- 边框：`#DCE6F2`。
- 成功：`#16A34A`。
- 警告：`#D97706`。
- 危险：`#DC2626`。

## 通知策略

- 使用 NSGo `ShowNotification` 和 `OnNotificationPress`。
- 通知 ID 使用事项类型和 ID，保证同一事项可更新。
- 标题示例：`新任务 · T123` 或 `Bug 状态变化 · B456`。
- 正文包含事项标题、项目和当前状态。
- 点击通知后打开主工作台并选中事项。
- 同一轮超过 5 条变化时，最多展示 5 条明细，并追加一条汇总通知。
- 用户可在托盘菜单关闭通知；关闭后仍保留工作台数据更新。

## 安全与隐私

- 账号密码只通过应用设置界面输入。
- 密码使用 NSGo 安全存储保存到 Windows 凭据管理器，不写入源码、配置文件、状态文件和日志。
- 日志仅记录时间、操作结果和错误类别，不记录账号密码、Cookie 或完整页面响应。
- 浏览器跳转仅允许配置的禅道来源。
- 所有禅道请求均为只读操作。

## 错误处理

- 登录失败：工作台提示检查账号密码，并提供重新登录入口。
- 会话失效：自动重新登录一次；仍失败则停止本轮变化判定并提示。
- 网络失败：保留旧数据，显示连接异常，下一轮重试。
- 解析失败：记录不含敏感数据的错误，保留旧数据，提示需要更新解析规则。
- 通知权限不可用：工作台仍正常更新，并提示系统通知未开启。

## 测试与验收

### 自动化测试

- 登录表单提取与提交参数构造。
- 任务/Bug 页面解析。
- 首次基线不通知。
- 新增事项通知。
- 状态变化通知。
- 相同数据重复拉取不通知。
- 请求失败不产生误报。
- 通知 ID 和跳转 URL 正确。

### 真实验收

- 使用提供的账号成功登录并读取“我的”数据。
- 主工作台显示真实任务和 Bug 汇总。
- 首次启动不补弹历史通知。
- 构造或等待一条新增/状态变化，验证右下角系统通知。
- 点击通知打开工作台并定位事项。
- 点击“在禅道打开”跳转正确详情页。
- 关闭窗口后程序仍在托盘运行，托盘可执行刷新和退出。
- 验证源码、配置和日志中不包含明文密码。
